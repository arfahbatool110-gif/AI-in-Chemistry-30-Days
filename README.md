# 🧪 AI in Chemistry & Drug Discovery: 30-Day Computational Portfolio

Welcome to my 30-day intensive computational chemistry and cheminformatics portfolio! As an **MPhil Chemistry graduate (3.94 CGPA)**, I built this repository to bridge the gap between traditional wet-lab chemistry and modern **Artificial Intelligence, Machine Learning, and Molecular Modeling**.

---

## 🚀 Key Skills & Tech Stack
* **Cheminformatics:** RDKit, DeepChem, SMILES Manipulation, Molecular Fingerprints (Morgan/MACCS)
* **Machine Learning & Deep Learning:** Scikit-Learn, Random Forest, SVM, Neural Networks, Graph Convolutional Networks (GCNs)
* **Structure-Based Drug Design:** DiffDock (Blind Docking), AlphaFold Protein Structure Analysis, Binding Pocket Identification
* **Drug-Likeness & Safety:** Lipinski’s Rule of Five, ADMET Property Prediction, Toxicity Screening
* **Materials Informatics:** High-throughput virtual screening for novel polymers and materials

---

## 📂 Repository Roadmap (30 Days of Code)

### 🔹 Phase 1: Foundations of Cheminformatics (Days 1–7)
* Molecular representation using SMILES and RDKit sanitization
* Substructure searching, similarity scoring (Tanimoto), and descriptor calculation
* Working with benchmark datasets (Delaney solubility, BACE, Tox21) via DeepChem

### 🔹 Phase 2: Machine Learning & Graph Neural Networks (Days 8–21)
* Building QSAR models using Random Forest and Support Vector Machines (SVM)
* Hyperparameter tuning and model evaluation (ROC-AUC, RMSE)
* Implementing Graph Convolutional Networks (GCNs) to learn directly from molecular graphs

### 🔹 Phase 3: Advanced Drug Discovery & AI (Days 22–30)
* **Protein-Ligand Docking:** Pocket analysis and binding pose prediction using DiffDock & AlphaFold
* **ADMET Pipelines:** Automated filtering of drug candidates for absorption, metabolism, and toxicity
* **De Novo Molecular Design:** Generating novel chemical structures with desired properties
* **Capstone Project:** Materials Informatics Virtual Screening Pipeline
